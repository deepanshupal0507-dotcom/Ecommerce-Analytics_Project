E-commerce Analytics Project

Project Overview

This project analyzes e-commerce business data using Python to identify insights related to orders, revenue, product categories, customer reviews, and customer locations.

Objectives

* Analyze total orders and revenue.
* Identify popular product categories.
* Understand customer review score distribution.
* Explore customer and business trends using data visualization.

Tools and Technologies

* Python
* Jupyter Notebook
* Pandas
* Matplotlib
* Data Analysis and Visualization

Key Analysis

* Total order quantity and revenue
* Most common order status
* Popular product categories
* Average customer review score
* Distribution of customer review scores

Project Files

* Ecommerce_analytics_Project-checkpoint.ipynb — Notebook checkpoint
* Ecommerce_analytics_Project.ipynb — Main analysis notebook

Conclusion

This project demonstrates the use of Python for exploratory data analysis and visualization to understand e-commerce business performance.
